# Dust v0.1.3

This release hardens Dust for real Dart and Flutter projects: safer runtime
contracts, stronger analyzer coverage, better routing/state behavior, improved
DB generation, and release automation for CLI binaries and pub packages.

## Highlights

- Adds CLI/runtime compatibility checks so `dust build`, `dust check`, and
  `dust doctor` can catch unsupported Dust package versions before generation.
- Adds source-first JSON APIs: generated `serialize`/`deserialize` helpers and
  Dart ecosystem `toJson`/`fromJson` mirrors.
- Adds typed route results with generated `Future<T?> push()` helpers.
- Adds router stack observer support and fixes deep-link/restored-stack edge
  cases.
- Adds `runAction` for stale-safe async ViewModel commands.
- Makes failed ViewModel initialization retry only through explicit
  `retryInit()`.
- Preserves translated ARB values during i18n generation and adds explicit
  source-locale sync behavior.
- Adds opt-in iOS locale metadata synchronization for Flutter i18n projects.
- Hardens Dust DB transactions, reversible migrations, SQLite connect options,
  mapper errors, and execution API naming.
- Automates codegen tool fingerprints so cache invalidation no longer depends
  on manual source registration.
- Adds `dust upgrade` support and release automation for platform CLI binaries.

## Install or update

Unix:

```sh
curl -fsSL https://raw.githubusercontent.com/y3l1n4ung/dust/main/install.sh | bash
```

Windows PowerShell:

```powershell
iwr https://raw.githubusercontent.com/y3l1n4ung/dust/main/install.ps1 -UseB | iex
```

To install this exact release:

```sh
DUST_VERSION=v0.1.3 curl -fsSL https://raw.githubusercontent.com/y3l1n4ung/dust/main/install.sh | bash
```
