# Dust v0.1.1

Patch release for the Dust CLI/codegen binary after v0.1.0.

## Highlights

- `dust` now reports `0.1.1` from the released CLI binary.
- Validation codegen keeps Dart model validation separate from Flutter form
  validators.
- Pure Dart packages emit `validate()` and `validateOrThrow()` without
  generated Flutter form helpers.
- Flutter packages still get generated form helpers.
- Router debug diagnostics are available for generated router troubleshooting.
- Apple Silicon release assets were aligned.
- Package README and pub.dev-facing documentation were polished.
