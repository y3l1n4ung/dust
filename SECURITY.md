# Security Policy

## Reporting Vulnerabilities

Do not report suspected vulnerabilities in public GitHub issues, discussions, or
pull requests.

Use GitHub private vulnerability reporting for this repository:

https://github.com/y3l1n4ung/dust/security/advisories/new

Include as much of the following as you can:

- affected package, crate, command, or generated code path
- Dust version, commit, or release tag
- operating system and toolchain versions
- minimal reproduction steps
- impact, affected data, or privilege boundary
- any workaround you already found

## Response

Maintainers will review private vulnerability reports before public disclosure.
Public fixes, advisories, and changelog notes will avoid exploit details until a
reasonable remediation path exists.

## Non-Security Bugs

Use public GitHub issues for normal bugs, feature requests, documentation
problems, and support questions.
